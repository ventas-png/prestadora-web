# prestadora-web

Nuevo sitio de prestadoradeservicios.com (Next.js, español e inglés).

- Textos de las dos versiones: `lib/content.ts`
- Páginas: `views/` (una por sección), rutas en `app/(es)` y `app/(en)/en`
- Fotos y logo: `public/img`

```bash
npm install
npm run dev   # http://localhost:3000
```

Se publica en Vercel desde la rama `main`.
